RedCell An agent that tries to break other agents, then tells you how to fix them.

RedCell tests an AI agent you own: it tries to get the agent to do unsafe things, confirms each finding with code checks, and gives you a fix for every one.

  1. TestNemotron Ultra holds a multi-turn conversation with the agent and adapts after each reply.
  2. ConfirmCode checks look for planted fake secrets and unsafe commands in the shell log, then replay the conversation on a fresh agent.
  3. Fix and re-testEach finding comes with a fix. Apply it and run the same test again.

Goals appear when you run an attack.
